## v1 Form Factor

- **Footprint:** ~90×60mm (matches Pi 5 credit-card form factor)
- **Mount:** 4× 41mm PVC suction cups, M5 bolt, window-mounted
- **Thermal:** Passive aluminum + copper heatsink
- **Housing:** v1 uses zip ties / rubber bands; v2 will be a 3D-printed matte-black enclosure with a silicone lens hood
